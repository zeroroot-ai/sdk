# Third-party license attributions

Every vendored file in this directory must have an entry below. Files without
an entry here will be flagged by the ontology loader and rejected at startup.

Author-contributed files (SOC2, NIST AI RMF authored hierarchies) do not
require an entry — they are original work by the Gibson project contributors.

## Discipline

For each vendored file add a block of the form:

```
## <filename>

Source:   <canonical download URL>
License:  <SPDX identifier or plain-English license name>
Version:  <version or commit hash of the source>
Retrieved: <ISO 8601 date>
Notes:    <any usage restrictions or attribution requirements>
```
